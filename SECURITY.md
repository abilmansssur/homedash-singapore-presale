# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability, exposed credential, or client-data concern.

Report it privately to `max@homedash.hk` with:

- the affected page, endpoint, or file;
- steps to reproduce;
- potential impact;
- any safe supporting evidence;
- your preferred contact details.

Do not include real client financial information, credentials, or destructive proof-of-concept data. Allow the project owner time to investigate and deploy a fix before public disclosure.

## Supported version

The current production deployment and the latest commit on `main` are supported. Older commits and preview deployments are not supported once superseded.

## Data handling

The public calculators are designed to process inputs for the current calculation without saving them in an application database. Contributors must not add logging, analytics, persistence, screenshots, or fixtures containing personal or client financial data without explicit review and approval.
